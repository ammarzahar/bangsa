# Page Structure

Public marketing + product:

- `https://bangsa.org/`

Group pages:

- `https://bangsa.org/{group_slug}`

Member profile pages:

- `https://bangsa.org/{group_slug}/member/{username}`

Authenticated app pages (recommended):

- `/login`
- `/register`
- `/subscribe`
- `/create-group`
- `/dashboard/platform`
- `/dashboard/group/{group_slug}`
- `/dashboard/group/{group_slug}/members`
- `/dashboard/group/{group_slug}/settings`
- `/dashboard/group/{group_slug}/approvals`
- `/dashboard/profile/{group_slug}`

Responsive behavior:

- Mobile-first card layout for member directory
- Sticky filter drawer on mobile, sidebar filters on desktop
- Avatar/profile sections collapse into tabs on small screens
