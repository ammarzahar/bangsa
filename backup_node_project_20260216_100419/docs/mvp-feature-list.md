# MVP Feature List

## Included in this MVP

- Paid subscription gate before group creation
- Multi-tenant groups with dedicated slug URLs
- Public/private group visibility
- Admin approval membership flow
- Rich member profiles with social links
- Searchable member directory with filters
- Featured members flag (admin-controlled)
- Platform owner dashboard + moderation controls
- Group admin dashboard analytics
- Seed data for two initial groups and platform owner

## Explicitly Excluded (per MVP scope)

- Chat
- Posts/forum
- Events
- Realtime notifications
